# Data access

No patient dataset is included in this repository. Access must be obtained from the original providers under their applicable terms.

The surgical analysis uses MIMIC-IV clinical data and linked MIMIC-IV-ECG recordings. Start with the official PhysioNet pages:

- [MIMIC-IV, version 3.1](https://physionet.org/content/mimiciv/3.1/)
- [MIMIC-IV-ECG](https://physionet.org/content/mimic-iv-ecg/)

Follow the analysis README for the precise input files and additional derived artifacts required. Dataset access alone does not provide the trained Hoopcare model or its predictions.

Keep source files and generated patient-level tables outside the Git working tree. Do not upload them to GitHub, including private issues, pull-request attachments or Actions artifacts. Keep authorized research storage and public source-code distribution separate.

Dataset identifiers and clinical records must not be added as examples. Use synthetic inputs for tests and demonstrations. Any future distribution of aggregate study results requires a separate review of the relevant release permissions and disclosure rules.
